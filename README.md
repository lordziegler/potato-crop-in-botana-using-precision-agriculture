# Potato crop in Botana using precision agriculture

Final project for a precision agriculture course: spatial variability of five soil chemical
properties at Granja Botana (Pasto, Nariño, Colombia), IDW / kriging interpolation, management
zones and an integrated soil fertility index (MIFS) for potato (*Solanum tuberosum*, Diacol Capiro).

## Layout

| Path | Content |
|---|---|
| `data/raw/` | Original soil-analysis sheet as delivered. Never edited. |
| `data/clean/` | Cleaned sample points, generated by `scripts/clean_soil_samples.py`. |
| `data/docs/` | Course guide and drone survey report. |
| `maps/` | QGIS project and farm boundary. |
| `scripts/` | Data-cleaning script. |

## Reproduce the clean data

Requires Python 3 with `pandas` and the GDAL Python bindings (`osgeo`). From the repository root:

```bash
python3 scripts/clean_soil_samples.py
```

Outputs:

- `data/clean/soil_samples.gpkg`: points in EPSG:9377 (MAGNA-SIRGAS 2018 / Origen-Nacional), for QGIS.
- `data/clean/soil_samples.csv`: same table with WGS84 `lat` / `lon`.
- `data/clean/qc_log.csv`: every value the script changed, with the reason.

## Data caveats

- Units are not stated in the raw sheet. Assumed: `om` %, `p` mg/kg, `k` and `al` cmol(+)/kg;
  `ec` units unknown. Verify against the lab report.
- Two corrections are assumptions and must be verified: M20 latitude and M22 organic matter
  (see `qc_log.csv`).
- Sampling date, depth and analytical methods are not recorded.
- 22 sampling points (21 for K and Al) are few for a reliable kriging variogram
  (Webster & Oliver, 1992, *J. Soil Sci.* 43:177–192).
